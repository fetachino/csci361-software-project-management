This repository presents my **Expense Tracker** project plan from **CSCI 36100 — Fundamentals of Software Project Management**. It documents how I translated a product idea into requirements, a delivery schedule, a proposed architecture, a user flow, and a verification plan.

> **Artifact scope:** This is a planning and requirements deliverable. The recovered files include the proposal, but not a complete Java implementation. The repository intentionally does not claim that the application was finished.

## Project overview

The proposed application helps users record expenses, organize them by category, set budgets, and understand spending patterns through reports and visualizations.

### Planned capabilities

- Account creation and authentication
- Expense entry with date, amount, and category
- Category-based budgeting
- Dashboard summaries and spending reports
- Persistent storage across sessions
- Charts for category and time-based spending patterns

## Delivery plan

The proposal used a three-week incremental plan:

1. **Planning and setup:** requirements, task breakdown, development environment, UML, and core interfaces.
2. **Feature implementation:** authentication, expense entry, categorization, budgeting, and reporting.
3. **Testing and refinement:** unit tests, user testing, defect fixes, documentation, and presentation.

## Engineering practices demonstrated

- Requirement decomposition and prioritization
- UML-oriented design planning
- Incremental delivery and time-boxed milestones
- Unit and user-test planning
- Stakeholder-oriented documentation
- Explicit scope boundaries and delivery risks
